# Project Instructions

## Language and stack
- This project uses the Encore programming language (`.enq`), Blaze, and SQLite.
- Follow the existing code style and project structure.
- Refer to README.md for development and verification commands.
- Store published package sources in the `encore-language-index` GitHub organization, with one repository per package.

## Tests
- Do not create or modify tests unless the user explicitly requests it.
- Run existing tests only when necessary for the current task.

## Speed and scope
- Perform only actions necessary to deliver the requested result.
- Prefer the smallest sufficient change.
- Avoid unrelated refactoring, improvements, and dependency changes.
- Inspect only files relevant to the task; do not perform a full project audit.
- Use the minimum sufficient verification; do not run every check by default.
- Stop when the request is complete. Briefly report the result and any checks performed.
